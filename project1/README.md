# Python Fundamentals

English | [简体中文](README_zh.md)

Independent console exercises for basic Python syntax.

Archived project retained for reference.

## Overview

The numbered scripts cover arithmetic, strings, branches, loops, functions and collections. Use synthetic values for exercises that ask for example records.

## Technology and Dependencies

Python 3 and its standard library.

## Repository Structure

Numbered `.py` scripts, from `1.1.py` through `6.2.py`.

## Quick Start

From this directory, after preparing the required input data and dependencies:

```bash
python 1.1.py
```
